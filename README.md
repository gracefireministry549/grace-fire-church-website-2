# Grace Fire Deliverance Healing Global World Ministry

Responsive church website for Grace Fire Deliverance Healing Global World Ministry in Isheri Osun, Lagos, Nigeria.

## Run locally

Requires Node.js 18 or newer.

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Sermons

Sermon PDFs are generated by Express at `/sermons/:slug.pdf`; no pre-generated PDF files are required.

## Configure Supabase storage for prayer and contact forms

The prayer and contact forms store submissions in the private Supabase database. The server sends inserts using a server-only key; the browser never receives this key. Row Level Security is enabled on both tables, and public/anonymous roles have no table permissions.

Set these environment variables in your hosting dashboard (such as Render):

- `SUPABASE_URL`: `https://xcvywoecvgzceyvqhjsr.supabase.co`
- `SUPABASE_SERVICE_ROLE_KEY`: the project's server-side service-role key from Supabase API settings. Keep this secret only in the hosting environment; never commit it to GitHub or add it to browser JavaScript.

Optional email notifications use Resend. Configure all three variables if you want the ministry to receive email alerts as well as stored messages:

- `RESEND_API_KEY`: API key from your Resend account.
- `MINISTRY_EMAIL`: inbox that should receive prayer requests and contact messages.
- `RESEND_FROM_EMAIL`: sender address verified by Resend for your domain.

Submissions are saved even when email notifications are not configured or temporarily unavailable. The website reports that distinction clearly. Never log message contents or prayer details.

## Anniversary date

The 9th Church Anniversary was held on August 30, 2026. The site marks it as a past event and hides the expired countdown. Update the event copy in `public/index.html`, `public/events.html`, and the date in `public/script.js` when the ministry confirms its next event.

## Security notes

- Request bodies are size-limited and form submissions have basic per-process rate limiting.
- The rate limiter is in-memory and is not shared across multiple service instances.
- Messages are emailed and are not written to application logs or stored in a database.
