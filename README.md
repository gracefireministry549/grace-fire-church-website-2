# Grace Fire Deliverance Healing Global World Ministry

Responsive church website for Grace Fire Deliverance Healing Global World Ministry in Isheri Osun, Lagos, Nigeria.

## Run locally

Requires Node.js 18 or newer.

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Sermons

Sermon PDFs are generated by Express at `/sermons/:slug.pdf`; no pre-generated PDF files are required.

## Configure prayer and contact form delivery

The forms deliver messages through the Resend email API. Set these environment variables in your hosting dashboard (such as Render):

- `RESEND_API_KEY`: API key from your Resend account.
- `MINISTRY_EMAIL`: inbox that should receive prayer requests and contact messages.
- `RESEND_FROM_EMAIL`: sender address verified by Resend for your domain.

Never commit API keys or other secrets to GitHub. Until all three values are configured, the API returns a clear setup message instead of falsely claiming that messages were delivered. Use the ministry's published phone number or WhatsApp as a fallback.

## Anniversary date

The 9th Church Anniversary was held on August 30, 2026. The site marks it as a past event and hides the expired countdown. Update the event copy in `public/index.html`, `public/events.html`, and the date in `public/script.js` when the ministry confirms its next event.

## Security notes

- Request bodies are size-limited and form submissions have basic per-process rate limiting.
- The rate limiter is in-memory and is not shared across multiple service instances.
- Messages are emailed and are not written to application logs or stored in a database.
